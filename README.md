# Fadejimi Aderele's portfolio

Personal site built with React, Vite and Tailwind CSS. Deployed to GitHub Pages by `.github/workflows/build.yml` on every push to `main`.

## Run it

```bash
npm install
npm run dev
```

## Edit the content

All text, links and projects live in `src/data/content.js`. To add a project, copy an entry in `projects` and lower `comingSoonCount` by one.
